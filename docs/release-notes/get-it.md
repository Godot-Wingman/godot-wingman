### ⬇️ Get it

**Already using Godot Wingman?** Your AI tells you about the new version and installs it if you say yes. Or run `godot-wingman update`.

**New here?** One command, then restart your AI app:

- Windows (PowerShell): `irm https://raw.githubusercontent.com/Godot-Wingman/godot-wingman/main/install/install.ps1 | iex`
- macOS and Linux: `curl -fsSL https://raw.githubusercontent.com/Godot-Wingman/godot-wingman/main/install/install.sh | sh`

Needs Godot 4.5 or newer. Other ways to install: [installation guide](https://github.com/Godot-Wingman/godot-wingman/blob/main/docs/INSTALL.md). Every file below is listed in `SHA256SUMS`.
