# Every frame counts

**Two bugs showed up while we recorded the README GIF. Neither survived.** 🎞️

### 🐛 Fixed

- **`step_frames` can count now.** Asking for 5 frames gave you 4, and asking for 1 gave you none, because the game was paused again before the last frame ran. Now 5 means 5 and 1 means 1. An input sent while the game is paused lands on the very next stepped frame, so frame-by-frame jumps work.
- **Broken code no longer freezes your game.** When `execute_game_script` got code that does not compile, Godot stopped the game in its debugger, and the tool (and every call after it) just waited for its timeout. The editor now compiles the code first and hands the errors straight back. The game keeps running.
