# 100 MB lighter

**The download went on a diet: a 1-2 MB file instead of a 100 MB executable.** 🪶

### ✨ Changed

- **Smaller install.** The installers use [Bun](https://bun.sh) (and install it when it is missing), then download the 1-2 MB `godot-wingman.js` instead of the 100 MB executable. The executable is still in every release, for when Bun can't be used (or set `GODOT_WINGMAN_USE_EXECUTABLE=1`).
- **Setup fixes old entries.** `godot-wingman setup` changes an entry that starts Godot Wingman another way, and keeps its options such as `--mode`.
- **Updates stay the same kind of file** you installed: a bundle stays a bundle, an executable stays an executable.
- **The website went dark** (the color scheme, not the site) and lives at https://godot-wingman.pages.dev.
