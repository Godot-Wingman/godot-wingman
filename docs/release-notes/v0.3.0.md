# One command to install

**From nothing to connected with one command, and the README speaks nine languages.** 🌍

### 🎉 Added

- **`create_project`.** The AI makes a new, empty Godot project (name and renderer) and opens it.
- **One-line installers** for Windows and for macOS and Linux. They download the newest release, check its checksum, install it and run setup. Files downloaded this way get no "unknown app" warning.
- **Setup** adds the server to Codex, Claude Desktop, Claude Code, Cursor, Gemini CLI and Windsurf, and keeps a copy of every settings file it changes. Codex gets a longer tool timeout.
- **README translations:** Spanish, Portuguese (Brazil), German, French, Russian, Simplified Chinese, Japanese and Korean.
