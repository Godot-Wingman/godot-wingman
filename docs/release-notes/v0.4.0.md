# Godot Pilot is now Godot Wingman

**New name, same partner in the editor. Godot Pilot is now Godot Wingman.** 🪽

### ✨ Changed

- **The rename.** The executable is `godot-wingman`, the addon folder is `addons/godot_wingman`, and the environment variables start with `GODOT_WINGMAN_`. Installing the addon removes the old `addons/godot_pilot` folder for you.
- ⚠️ **Coming from 0.1 to 0.3?** Those versions can't update themselves to this one. Install again with the one-line installer below.
- **Double-clicking the executable explains what it is** and offers to run setup, instead of showing an empty window.
- **The Windows executable has a proper name tag:** name, description and version in its file properties.
