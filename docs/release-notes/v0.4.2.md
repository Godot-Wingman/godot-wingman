# No more ghost apps

**Setup stopped seeing ghosts.** 👻

### 🐛 Fixed

- **`godot-wingman setup` no longer sets up apps you don't have.** Removed apps leave their folders behind, and some apps create folders for others (Antigravity creates `~/.gemini` and `~/.codeium/windsurf`). Setup took such folders for Gemini CLI, Windsurf or Cursor. Now an app counts as installed only when its command is on the PATH, its program folder exists, or it has written its own settings file.
