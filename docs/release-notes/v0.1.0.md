# Wheels up

**The first release. Your AI gets a seat in the Godot editor.** 🛫

A local MCP server and a Godot addon: your AI app builds scenes, writes scripts, runs the game, plays it with real input and reads the errors, all in the open editor and with undo.

### 🎉 What's inside

- **Editing:** scenes, the inspector, GDScript and C# scripts, project settings, signals, resources and files, undoable with Ctrl+Z where the editor supports it.
- **Playtesting:** run, pause and step the game, send real keys, gamepad and mouse input, look at live nodes, take screenshots, read errors with stack traces.
- **Building:** animations, tilemaps, UI, 3D scenes, shaders, audio buses and exports.
- **Docs from your own Godot:** the class reference comes from the Godot version you have installed.
- **You stay in charge:** permission modes `full`, `confirm` (an Allow / Deny dialog) and `read-only`, a panel listing every change, and a way back to how things were before any step.
- **Stays out of your game:** an export plugin keeps the addon out of exported games.

The full list is in the [changelog](https://github.com/Godot-Wingman/godot-wingman/blob/main/CHANGELOG.md#010---2026-11-26).
