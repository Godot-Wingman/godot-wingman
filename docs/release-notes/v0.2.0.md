# AIs that talk to each other

**Your AI now notices what you do, and several AIs can share one editor.** 🤝

### 🎉 Added

- **News for the AI.** At the end of its tool results, the AI hears when you undo or redo a change (and whether it was its own), change things by hand, or go back to an earlier step in the panel.
- **Several AIs in one editor.** They are told when another AI joins or leaves, can message each other with the new `tell_other_ais` tool, and an AI that joins late gets the recent messages. You can write to the AIs from the panel too.
- **Update check.** At most once a day the server reads the list of releases on GitHub and tells the AI about a newer version. A new tool and a new command install it after checking its SHA-256 checksum. Off with `--no-update-check`.
- **`SHA256SUMS`** in every release.
- **Nightly end-to-end tests** with a C# project and a Rust GDExtension, also run before every release.
- The addon folder carries its own copy of the license.
