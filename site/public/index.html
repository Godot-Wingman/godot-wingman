Let your AI use the Godot editor.

Godot Wingman is an MCP server that runs on your computer. Your AI app sees the editor, builds scenes, writes and checks scripts, runs the game, plays it with real input, then reads the errors and fixes them.

Install Source on GitHub

It works inside the open editor.

An addon connects the editor to your AI app, so the AI changes the real project you are looking at, and scene changes go through Godot's undo history.

Install with one command.

The installer downloads the newest release, checks its SHA-256 checksum and adds Godot Wingman to the AI apps it finds: Codex, Claude Desktop, Claude Code, Cursor, Gemini CLI and Windsurf. Other MCP clients can add it by hand.

  1. Run the commandFiles downloaded this way get no "unknown app" warning. You can read the scripts first.
  2. Restart your AI appA copy of every settings file the installer changed is kept next to it.
  3. Ask for a game"Create a new Godot game in C:/games/my-game", or "Open my Godot project in D:/games/platformer".
PowerShell
irm https://raw.githubusercontent.com/Albis0/godot-wingman/main/install/install.ps1 | iex

Installs to %LOCALAPPDATA%\Programs\godot-wingman and adds it to your PATH.

Requires Godot 4.5 or newer. Every change is tested with Godot 4.5.2, 4.6.3 and 4.7.2. Installing by hand: installation guide.

Everything stays on your computer.

The connection to the editor only listens on 127.0.0.1 and needs a secret token. Godot Wingman sends nothing about you or your project.

You decide what it may change.

Pick a permission mode in the panel, or with --mode when you add Godot Wingman to your AI app. When the two differ, the stricter one wins.

Full

--mode full · default

The AI uses every enabled tool.

Confirm each change

--mode confirm

The AI looks freely. Before every change, Godot shows what it wants to do (for GDScript, the whole code) and you click Allow or Deny.

Read-only

--mode read-only

The AI only looks. Tools that change files, run GDScript, start the game or send input are hidden.

The panel lists every change and can put scripts, scenes, resources and settings back to how they were before any of them. When you press Ctrl+Z, change something by hand or go back, the AI is told with its next step.

GDScript, C# and GDExtension.

GDScript is fully supported. Every night, and before each release, separate tests also check a C# project (Godot .NET) and a GDExtension written in Rust.

GDScript

Scripts are written, checked by Godot's own parser and attached.

C#

With the .NET build of Godot, the AI writes and edits C# scripts; they are built with dotnet build.

GDExtension

Rust and C++ classes from your extensions, with their properties, methods and signals.

Questions

Does Godot Wingman send my project anywhere?

No. It sends nothing about you or your project: no accounts, no cloud, no telemetry. To tell you about new versions it downloads the list of its releases from GitHub at most once a day (turn it off with --no-update-check). Your AI app is separate: what the AI reads goes to the AI model you use, under that provider's rules.

Can I sell a game I made with it?

Yes. The addon is an editor tool and is not included in exported games (a test checks this on every change). Your game's code and assets are yours, under any license you choose.

Is the code the AI writes for me under the AGPL?

No. The AGPL-3.0 covers Godot Wingman's own files: the server and the addons/godot_wingman folder. You only have to share source code when you give Godot Wingman itself to others, or let others use a changed version over a network. This is a summary, not legal advice.

How does it get updated?

When a new version is out, the AI tells you and installs it if you agree. The download is checked against the release's SHA-256 checksums. You can also run godot-wingman update.

Which Godot versions work?

Godot 4.5 or newer. Every change is tested with Godot 4.5.2, 4.6.3 and 4.7.2.
