Let your AI use the Godot editor like a person.

Godot Wingman is an MCP server that runs on your computer. Your AI assistant sees the editor, builds scenes, writes and checks scripts, runs the game, plays it with real input, then reads the errors and fixes them.

What it does

It works inside the open Godot editor through an addon, so the AI changes the real project you are looking at.

↶

Live changes with undo

Scene and inspector changes go through Godot's undo history, so you can press Ctrl+Z.

◉

It sees

Screenshots of the editor, the 2D/3D viewport and the running game, with camera control.

▶

It plays

Real input: holding keys, timing, sequences, frame stepping and "wait until a condition is true".

Several AIs, one editor

AIs in the same editor tell each other what they are changing, and you can write to all of them from the panel.

Small context

121 tools in 20 toolsets. The AI turns on only the groups it needs: scenes, scripts, animation, tile maps, UI, 3D, shaders, audio, export…

Install in one command

The installer downloads the newest release, checks its SHA-256 checksum and adds Godot Wingman to the AI apps it finds.

Windows PowerShell
irm https://raw.githubusercontent.com/Albis0/godot-wingman/main/install/install.ps1 | iex
macOS and Linux Terminal
curl -fsSL https://raw.githubusercontent.com/Albis0/godot-wingman/main/install/install.sh | sh
  1. Run the command. Files downloaded this way get no "unknown app" warning. You can read the scripts first.
  2. Restart your AI app. A copy of every settings file the installer changed is kept next to it.
  3. Ask: "Create a new Godot game in C:/games/my-game", or "Open my Godot project in D:/games/platformer".

How it works

Everything runs on your computer. The connection to the editor only listens on 127.0.0.1 and needs a secret token.

You stay in control

The Godot Wingman panel at the bottom of the editor lists every change the AI made and can put scripts, scenes, resources and settings back to how they were before any of them. When you press Ctrl+Z, change something by hand or go back, the AI is told with its next step.

Permission modeWhat the AI may do
full (default)Use every enabled tool.
confirmLook freely. Before every change, Godot shows what the AI wants to do (for GDScript, the whole code) and you click Allow or Deny. You can allow one tool for the rest of the session.
read-onlyOnly look. Tools that change files, run GDScript, start the game or send input are hidden.

Languages

GDScript is fully supported. Every night, and before each release, separate tests also check a C# project (Godot .NET) and a GDExtension written in Rust.

GDScript

Scripts are written, checked by Godot's own parser and attached.

C#

With the .NET build of Godot, the AI writes and edits C# scripts; they are built with dotnet build.

GDExtension

Rust and C++ classes from your extensions, with their properties, methods and signals.

Questions

Does Godot Wingman send my project anywhere?

No. It sends nothing about you or your project: no accounts, no cloud, no telemetry. To tell you about new versions it downloads the list of its releases from GitHub at most once a day (turn it off with --no-update-check). Your AI app is separate: what the AI reads goes to the AI model you use, under that provider's rules.

Can I sell a game I made with it?

Yes. The addon is an editor tool and is not included in exported games (a test checks this on every change). Your game's code and assets are yours, under any license you choose.

Is the code the AI writes for me under the AGPL?

No. The AGPL-3.0 covers Godot Wingman's own files: the server and the addons/godot_wingman folder. You only have to share source code when you give Godot Wingman itself to others, or let others use a changed version over a network. This is a summary, not legal advice.

How does it get updated?

When a new version is out, the AI tells you and installs it if you agree. The download is checked against the release's SHA-256 checksums. You can also run godot-wingman update.

Which Godot versions work?

Godot 4.5 or newer. Every change is tested with Godot 4.5.2, 4.6.3 and 4.7.2.
